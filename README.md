### Currently working on

**Kurdish Sorani NLP** — a public benchmark and a fine-tuned model for a language
that open-source AI mostly ignores. I speak it, so I can build the eval set that
nobody else is building.

**Alpha IOI** — a native GTK4 desktop client for multiple LLM providers. No
Electron, no web view. API keys live in the system keyring, conversations are
plain JSONL files you own, and there's an offline demo provider so it works
before you configure anything.

### How I work

Everything local-first by default — no telemetry, no silent uploads, keys in the
keyring instead of a config file. I'd rather ship a smaller thing that actually
runs on your laptop than a demo that needs someone else's server.
